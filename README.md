# PL101ProjectTemplate

Coursework from Nathan's University PL101 (a programming-languages course), written in 2012. Two JavaScript exercises:

- `mus/` - a compiler for MUS, the course's tiny music-notation language: a PEG grammar (`parse.peg`), the compiler (`compiler.js`) and a tester (`tester.js`).
- `schemm/` - SCHEMM, the beginnings of a Scheme interpreter: PEG grammar, parser, and Mocha tests.

Written by hand in 2012, long before AI assistance. The code has not been run since; treat it as a course artifact, not maintained software. (History note: commits are under the author's old `vandeput` handle.)
